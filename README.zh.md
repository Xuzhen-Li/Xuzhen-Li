我研究植物古基因组学，以及葡萄和其他多年生植物的群体遗传学。

这里的公开仓库主要包含 Vitis 泛基因组、基因注释、捕获面板基因分型和古 DNA 的分析流程与笔记。此外还有一个论文配图库和几个小型分析工具。

## 研究方向

| 主题 | 仓库 |
| --- | --- |
| 泛基因组与葡萄基因组 | [vitis-pangenome](https://github.com/Xuzhen-Li/vitis-pangenome)；[grapevine-plastid](https://github.com/Xuzhen-Li/grapevine-plastid)（进行中）；[vitis-te](https://github.com/Xuzhen-Li/vitis-te)（进行中） |
| 基因组注释 | [gene-structure-annotation](https://github.com/Xuzhen-Li/gene-structure-annotation)；[gene-function-annotation](https://github.com/Xuzhen-Li/gene-function-annotation) |
| 群体遗传学 | [qbar](https://github.com/Xuzhen-Li/qbar)；[TrioConcordance](https://github.com/Xuzhen-Li/TrioConcordance)；[genomics-theory-mining](https://github.com/Xuzhen-Li/genomics-theory-mining)；[vitis-popgen](https://github.com/Xuzhen-Li/vitis-popgen)，面向公开或已发表数据的 *Vitis* 群体结构、基因流、驯化、选择、群体历史及相关分析的方法目录 |
| 捕获面板基因分型 | [grapeancestry](https://github.com/Xuzhen-Li/grapeancestry)；[grapevine-chip](https://github.com/Xuzhen-Li/grapevine-chip)；[gtbs-chip-service-kit](https://github.com/Xuzhen-Li/gtbs-chip-service-kit) |
| 古 DNA | [grapevine-adna](https://github.com/Xuzhen-Li/grapevine-adna)，*Vitis* 古 DNA 方法目录，涵盖采样、超净室操作、提取、文库制备、捕获或鸟枪法测序、预处理、比对、损伤鉴定、污染、低深度基因分型、测年以及与现代葡萄一起做的下游分析 |
| 开放研究方向 | [vitis-open-directions](https://github.com/Xuzhen-Li/vitis-open-directions)，仅使用公开数据的葡萄（*Vitis*）基因组学研究方向，每个都是从下载到出图的可运行方案 |
